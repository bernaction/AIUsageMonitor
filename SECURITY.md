# Security Policy

## Supported versions

AI Usage Monitor is currently an early-stage project. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or include credentials, account information, request headers, or the contents of `~/.codex/auth.json` in any report.

Use GitHub private vulnerability reporting from the repository's **Security** tab when available. If that option is not available, contact a maintainer privately and share only the minimum information needed to reproduce the issue.

Include:

- a clear description of the vulnerability;
- the affected version or commit;
- steps to reproduce the issue;
- the expected security impact;
- any suggested mitigation, if known.

Maintainers will acknowledge the report, investigate it, and coordinate disclosure and a fix when appropriate.
